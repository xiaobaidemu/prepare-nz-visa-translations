# 版式重建方法

## 选择生成方式

- 页面包含不规则表格、合并单元格、重复字段或需要浏览器自动换行的密集文本时，使用 HTML/CSS。
- 页面需要精确坐标、圆形印章、多层矢量元素或完全确定的 PDF 输出时，使用 ReportLab。
- 主体表格适合 HTML、译者页和 PDF 合并适合 ReportLab 时，使用混合方式。

## HTML 一比一重建

1. 读取原始 PDF 的点数尺寸，或换算为毫米。
2. 将 `../assets/vector-page-template.html` 复制到任务工作目录。
3. 设置 `@page { size: 宽mm 高mm; margin: 0; }`，并让 `.page` 使用相同尺寸。
4. 先重建大区域：页面外框、证件卡、页头、表格、说明、页脚、照片和印章。
5. 规则表单使用 CSS Grid；带合并单元格的区域使用 `<table>`、`rowspan` 和 `colspan`。
6. 只有真正固定的位置才使用绝对定位；长段落保持正常文档流，避免截断。
7. 几何尺寸使用毫米，字号使用点。
8. 使用 `scripts/render_html_to_pdf.py` 打印，并检查生成的 PDF，不能只看浏览器页面。

## ReportLab 矢量重建

1. 使用与原件完全相同的页面尺寸创建画布。
2. 先绘制背景与外框，再绘制文字。
3. 表格使用 `Table` 和 `TableStyle`；长字段必须用 `Paragraph` 自动换行。
4. 译文中的印章使用矢量圆环和居中的英文文字重建。纯英文重建页不得粘贴无法阅读的中文印章像素。
5. 裁切、旋转和透明度操作必须用 `saveState()` 与 `restoreState()` 包围。
6. 字段值和字段标签使用不同样式，以保持原件的视觉层级。

## 保真规则

- 先匹配区域比例，再微调颜色和装饰细节。
- 保留原件留白，不得为了填满页面而拉伸小尺寸证件。
- 保持照片宽高比，主动控制裁切，不得压扁人像或过度裁掉头部。
- 空白单元格必须在生成时就是空白，不能事后涂抹。
- 翻译所有印章与盖章文字。只有部分可读时，翻译可读部分并添加 `(partly obscured)`。
- 字号不得小于 7 pt。内容过密时，优先增大字段宽度、缩小内边距或换行，不要先缩小字号。
- 不得加入原件不存在的装饰性副标题、认证徽章、水印或红色说明。

## 视觉比对循环

1. 将原件和译文按相同像素尺寸渲染为 PNG。
2. 比较页面边界、表格线、列宽、行高、照片裁切、标题位置和印章位置。
3. 在整页视图检查整体平衡，在 100% 缩放下检查可读性。
4. 修改矢量源文件、重新生成 PDF，并重复检查，直到没有截断和意外重叠。
